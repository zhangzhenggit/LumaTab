## 详细说明

```
LumaTab 只做一件事：把新标签页变干净。

没有广告，没有推荐位，没有"热门资讯"，没有账号登录，也不收集任何数据。
打开新标签页，你看到的只有壁纸、搜索框，和你自己放上去的快捷方式。


【搜索框用的是你自己的搜索引擎】

LumaTab 不自带搜索引擎，也不修改你的默认搜索引擎设置。
搜索框通过 Chrome 官方的 chrome.search API 把内容交给你在 Chrome 设置里选定的引擎——
你用的是 Bing 或百度，它就走 Bing 或百度。输入的是网址则直接跳转，不经过搜索引擎。


【它有什么】

· Bing 每日壁纸
  每天自动更新，也可以固定你喜欢的某一张。近 7 天的图片都在设置里，随时翻回去。
  另外内置 14 组纯色渐变背景，不想要照片的时候可以换成它。

· 可拖放的快捷方式与分组
  拖到另一个图标上就合并成分组，拖到缝隙里就换位置。分组里的图标拖出面板即移出，
  分组只剩一个图标时自动解散。整个过程网格不会乱跳——拖动开始时就锁定了布局，
  你瞄准的东西不会从光标底下溜走。

· 自动获取网站图标
  从站点自己声明的 favicon、apple-touch-icon 和 Web App Manifest 里取，取不到才用
  字母图标。也可以自己指定字母和底色。

· 亮度与模糊
  作用在壁纸本身的滤镜，而不是盖一层灰蒙蒙的遮罩。照片还会自动测量亮度并适度压暗，
  让网站图标看得清；你手动调过之后就以你的设置为准。

· 数据在你手里
  一键导出全部快捷方式为 JSON，换电脑或重装时导入即可。没有云端，也就没有"服务器
  故障导致数据丢失"这回事。


【关于权限】

安装时只申请三项：
· storage —— 把你的快捷方式和设置存在本机
· search —— 调用 Chrome 官方接口，把搜索交给你自己选定的默认搜索引擎
· https://www.bing.com —— 取每日壁纸

抓取网站高清图标需要访问站点的权限，这一项是可选的，安装时不申请，默认不授予。
不授予也能正常用，只是图标改用 Chrome 本地已有的记录（通常 16/32px）。想要高清图标
时，在新标签页顶部点一下「允许」即可，随时可以收回。

即使授予了，扩展也只会去读你自己添加的那些网站的图标，不会浏览、不会遍历、不注入
任何脚本、不修改任何网页内容。


【不做什么】

· 不收集浏览历史、书签、Cookie、密码
· 不使用统计、埋点、崩溃上报或广告 SDK
· 不建立账号，不生成设备标识
· 不把你添加的网址发送给我们或任何第三方
· 卸载即彻底删除本机全部数据

隐私政策：https://zhangzhenggit.github.io/LumaTab/
```

## 单一用途说明（Single purpose，后台必填）

审核会拿这段和实际权限对照，写得越具体越顺。

```
本扩展的唯一用途是替换 Chrome 的新标签页，在这一个页面上提供壁纸、搜索框和用户自己
管理的快捷方式。除此之外不提供任何其他功能。

搜索框不构成独立功能，也不改变用户的搜索体验：它不自带搜索引擎，而是调用 Chrome 官方的
chrome.search.query()，由浏览器把查询交给用户在 Chrome 设置中选定的默认搜索引擎。扩展
未声明 chrome_settings_overrides，不修改默认搜索引擎，代码中也不包含任何搜索引擎的地址。
```

## 各项权限用途说明（后台逐项必填）

后台把所有主机权限合成**一个**输入框，必需的和可选的都写在里面，不像 manifest 里分开。

**storage 权限的理由**
```
保存用户的快捷方式、分组结构和壁纸设置。全部存储在本机 chrome.storage.local，
不上传任何服务器，也不建立账号。
```

**search 权限的理由**
```
新标签页上的搜索框通过 chrome.search.query() 提交查询，由浏览器交给用户在 Chrome 设置中
选定的默认搜索引擎处理。这样做正是为了尊重用户已有的搜索引擎设置：扩展不自带、不指定、
也不修改默认搜索引擎（未声明 chrome_settings_overrides），代码中不包含任何搜索引擎地址，
扩展也无法读取搜索词或结果页内容。
```

**favicon 权限的理由**
```
读取 Chrome 本地已有的网站图标缓存，用于在新标签页上显示快捷方式图标。这是纯本地
读取，不产生网络请求。当用户未授予可选的站点访问权限时，这是图标的唯一来源。
```

**主机权限的理由**（一个框里写完，覆盖必需与可选两部分）

> 下面每段都是**一整行**，段内没有换行——后台的输入框只有 1,000 字符，直接整段复制
> 粘贴即可，不要保留本文档排版带来的折行。

```
本扩展申请两类主机权限，用途都只是取图片，不修改任何网页内容。

一、https://www.bing.com/（必需）：获取 Bing 每日壁纸的图片列表（HPImageArchive 接口）与图片文件，用于新标签页背景。仅此一个域名，不读取其他站点内容。

二、http://*/* 与 https://*/*（可选，声明在 optional_host_permissions 中，安装时不申请、默认不授予）：读取用户自己添加到新标签页上的那些网站所公开声明的图标资源，即 /favicon.ico、页面中的 <link rel="icon"> 与 apple-touch-icon、以及 Web App Manifest 中声明的图标。全部为 GET 请求，只读取图标文件。用户可在新标签页顶部的提示条或设置面板中自行授予与收回；未授予时功能不中断，图标改用 favicon 权限提供的本地记录。

本扩展没有 content script，不注入或执行任何页面脚本，也不会把用户添加的网址发送给开发者或任何第三方。
```
