一句话说明

LumaTab 不收集、不上传、不共享任何个人数据。 所有内容只保存在你自己浏览器的本地存储中，开发者无法访问。

我们保存什么，保存在哪

LumaTab 没有服务器，也没有任何后端账号体系。以下数据全部通过 Chrome 的chrome.storage.local 和 Cache Storage 保存在你本机的浏览器配置目录中：

卸载扩展时，Chrome 会一并删除上述全部内容。你也可以随时在扩展的设置面板中「导出为 JSON」自行备份。

扩展会连接哪些网络地址

LumaTab 只发起两类网络请求，都不携带任何身份标识：

  1. https://www.bing.com —— 获取每日壁纸的图片列表与图片文件。这是安装时唯一申请的站点权限。
  2. 你自己添加的网站（需要你另行授权，见下节）—— 读取该网站公开声明的图标（/favicon.ico、页面中的 <link rel="icon">、apple-touch-icon、Web App Manifest 中声明的图标）。

这些请求由扩展的后台 Service Worker 发出，只读取图标资源，不修改网页内容，不注入任何脚本，也不会把请求内容发送到第三方。

需要特别说明的是：扩展不会把你添加的任何网址发送给我们或任何第三方。图标是从你的电脑直接向该网站请求的——正因为如此，才需要下面这项权限。

关于 http://*/* 与 https://*/* 权限（可选，默认不授予）

这项权限是可选权限，安装时不申请，默认处于未授予状态。未授予时扩展完全可用，只是图标改用 Chrome 本地已有的记录（通常只有 16/32px）。

你可以在新标签页顶部的提示条上点「允许」，或在设置面板最底部的「网站图标」中授予；授予后可随时在同一处收回，也可以在 chrome://extensions 中收回。

授予后，这项权限仅用于读取你自己添加的那些网站的图标。扩展不会浏览、不会遍历、也不会主动访问你没有添加到新标签页上的任何网址。它没有 content script，不会在你访问的网页中运行任何代码。

图标请求沿用 Chrome 当前的系统代理与网络设置，扩展不另设代理、不改变路由。

关于 favicon 权限

这是安装时申请的必需权限，用于读取 Chrome 本地已有的图标缓存。在未授予上述站点权限时，它是图标的唯一来源；在已授予时，它是网站图标取不到（例如需要登录、或位于内网）时的兜底。这是纯本地读取，不产生网络请求。

我们不做的事

  • 不收集浏览历史、书签、Cookie、密码或任何表单内容
  • 不使用分析、埋点、崩溃上报或广告 SDK
  • 不建立用户账号，不生成设备标识
  • 不向任何第三方出售、出租或共享数据
  • 不在你访问的网页中注入或执行任何代码

儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集其任何信息——事实上它不收集任何人的信息。

政策变更

如果未来版本引入了会改变上述任何一条的功能，本文件将在该版本发布前更新，并在扩展的更新说明中注明。
